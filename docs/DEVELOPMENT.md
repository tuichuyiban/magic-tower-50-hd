# 魔塔 50 层 · 高清重制（全五区，1F – 50F + 隐藏 0F）

基于 **HTML5 Canvas + TypeScript + Vite** 的经典「50 层魔塔」网页高清重制。**全五区（1F–50F）+ 隐藏 0F 已实现**：地图、剧情、数值、商店价格与隐藏要素都以原版数据为准（主要依据 h5mota 51 号塔；资料与核对见 [`docs/research.md`](./docs/research.md)），美术为全新绘制的高清像素画。

## 快速开始

需要 Node.js 18+（推荐 20+）。

```bash
npm install          # 安装依赖
npm run dev          # 开发服务器（默认 http://localhost:5173 ，局域网设备也可访问）
npm run build        # TypeScript 类型检查 + 生产构建，输出到 dist/
npm run preview      # 预览构建结果（默认 http://localhost:4173 ）
npm run simulate     # 数值核对 + 第一区通关路线模拟（约 5–12 分钟，结果写入 docs/zone1-route.txt）
npm run simulate:quick  # 只做数值 / 规则检查（不到 1 秒）
npm run simulate2    # 第二区：数值与规则核对（不到 1 秒）
npm run route2       # 第二区通关路线：贪心规划 + 真实引擎重放（约 1 秒，加 M_WRITE=1 写入 docs/zone2-route.txt）
npm run import-maps  # 由 docs/h5-51-source/ 中的原版地图重新生成 src/game/floors/zone1.ts / zone2.ts
```

> 平板试玩：电脑与平板连同一 Wi-Fi，运行 `npm run dev` 后用平板浏览器打开终端里的 `Network` 地址，横屏最佳。
> 地址加上 `?new` 可跳过开始画面，直接开新游戏；加上 `?test` 直接进入**试玩模式**（从 11F 开始体验第二区，见下文）。

## 第一区内容

- **10 层原版地图**：由原版数据（13×13 去掉外圈墙 → 11×11）自动导入，楼梯落点与原版一致；换层有黑场过渡和楼层横幅。
- **序章与监狱**：以 1000/100/100 + 神圣剑盾开局；3F 魔王伏击后属性变为 400/10/10，被关进 2F 监狱，与小偷一起越狱。
- **NPC 与商店**（中文对话框，打字机效果）：
  - 3F 老人赠送怪物手册；4F 祭坛「供奉金币提升力量」，价格 20 + 10·t·(t+1)（20 / 40 / 80 / 140 …），可选 生命 +100·(t+1) / 攻击 +2 / 防御 +4；
  - 6F 商人 50 金币卖 1 把蓝钥匙，7F 商人 50 金币卖 5 把黄钥匙；买完再对话会给出情报并离开；
  - 4F、6F 老人的提示；2F 铁门后的老人与祝福商人（需打败中级卫兵，第一区内打不过，与原版相同）。
- **机关**：8F 打败两名初级卫兵打开机关门（红钥匙）；10F 骷髅队长伏击 —— 8 只骷髅从两侧小屋走出包围勇士，清空后打开通往队长的门，击败队长出现奖励和隐藏的上楼梯；小偷来告别。
- **隐藏要素**：5F、9F 的暗墙（撞上即打开），后面分别是铁剑、铁盾；10F 隐藏楼梯。第一区以外的隐藏红钥匙、圣水等已在调研笔记中记录，留给后续区域。
- **怪物**：9 种，数值与原版逐项一致（无经验值，无特殊能力）；均有高清像素待机动画。NPC（老人、商人、小偷、魔王、魔法警卫、祭坛）同样有待机动画。
- **道具**：红 / 蓝血瓶 50 / 200，红 / 蓝宝石 +1，铁剑 / 铁盾 +10，三色钥匙，魔杖（楼层传送，开局即拥有），备忘录（自动记录情报对话），怪物手册。
- **战斗**：沿用已确认的战斗表现与公式；获得怪物手册后地图上显示伤害与临界值（存档菜单中可开启「未获得手册时也显示」辅助选项，默认关闭 = 原版）。
- **楼层传送**：魔杖开局即拥有（与 h5mota 51 号塔一致：开局事件 `setValue item:fly = 1`）；只能飞往到过的楼层，须站在楼梯上或楼梯旁（`flyNearStair: true`，同样取自 51 号塔）。1F 地上那根魔杖仍保留（原版地图如此），拾取后无额外效果。
- **楼层传送器**（仿 H5 样板）：中央是所选楼层的大幅地图预览（按该层**当前状态**实时绘制，含已清的怪 / 已开的门），旁边显示楼层号与名称；右侧 ▲ / ▼（±1 层）与其外侧的 ▲▲ / ▼▼（±10 层）按钮、鼠标滚轮（±1）、键盘 ↑↓（±1，或 W/S）与 ←→（±10，或 A/D、PageUp/PageDown）、触屏上下滑动切换楼层。规则与样板 `actions._getNextFlyFloor(delta)` 相同（ckcz123/mota-js `libs/actions.js` 的 `_clickFly` / `_keyDownFly` / `_keyUpFly`，`libs/ui.js` 的 `drawFly`）：沿该方向只数**到过的**楼层、未到过的跳过；不足 10 个时停在该方向最远的到过楼层；该方向已无可去楼层时 ▲ 与 ▲▲（或 ▼ 与 ▼▼）一起禁用；Enter 或「传送到 nF」确认，Esc /「取消」退出。切换时预览快速上下滑入滑出（120 ms），确认后进入原有的换层淡入淡出。站在楼梯旁才能打开（规则不变）。
- **存档 / 读档**（仿 H5 样板）：存档页与读档页分开，每页 4 格（2×2）× 100 页 = 400 个手动档位 + 1 个自动存档（每次换层，显示在读档页顶部）；每格显示存档时的**地图缩略图**（128×128 WebP，约 5 KB，单独存放；空间不足时自动舍弃缩略图、保住存档）、楼层、生命 / 攻击 / 防御与时间，可删除；底部显示本地存储占用。
- **回退一步**：每次动作前记录完整快照（全部楼层、属性、标志、备忘录）；战斗、开门、拾取、商店购买、NPC 剧情、换层 / 传送 / 读档 / 重新开始之后都能回退，单纯走路不占历史；最多保留 100 步。剧情（3F 伏击 → 监狱、8F 机关门、10F 伏击）同样可以完整回退。剧情或对话进行中不能回退。
- **背包**（取代原左栏「怪物情报」框）：4×2 图标网格显示勇士拥有的道具（现有魔杖、怪物手册、备忘录），消耗品显示数量；鼠标悬停 / 触屏长按显示名称、快捷键与说明；点击即使用（魔杖 → 楼层传送器，手册 → 怪物手册，备忘录 → 留言簿）；超过 8 个自动分页。道具走通用注册表 `src/ui/inventory.ts`：`inventory.register({ id, name, desc, icon, count, permanent?, usable?, use?, hotkey? })`，以后的上下楼器 / 升降之翼、圣水、破墙镐、炸弹、十字架、幸运金币等注册即可接入。
- **怪物悬停浮窗**：仅在支持悬停的电脑上（`pointerType === 'mouse'` 且 `(hover: hover)`），鼠标停在怪物上时旁边显示名称、生命 / 攻击 / 防御 / 金币、预计伤害、临界与 1 防减伤（无手册且未开辅助时只显示名称与基础属性）。触屏点击永远是寻路 / 攻击，不弹任何情报。
- **自动功能**（仿 h5mota 样板 `autoGet` 插件，设置中可分别开关，均保存在 localStorage）：
  - **触发时机**与样板 `autoGet` 插件相同（它包装了 `control.moveOneStep` / `moveDirectly`，每次勇士实际走完一步后调用 `core.auto()`；勇士脚下有事件时不执行）：只在勇士**自己走出一步**之后立即执行一批（包括走上去拾取道具的那一步、点击寻路的每一步）。单纯打怪 / 开门（勇士不移动）不触发，下一步才会触发；踏上剧情格的那一步不触发。经楼梯 / 魔杖 / 剧情到达新楼层、读档、回退、重新开始、切换设置、静止不动时都**不会**触发——新楼层要等勇士走出第一步。
  - **默认全部关闭**（「含血瓶」子选项默认勾选，仅在开启自动拾取后生效）；设置版本升到 2，旧版本保存的开关会被重置为关闭一次。
  - **自动清怪**：每次行动后，自动击败**伤害为 0** 且无需经过门 / 其他怪物即可到达的怪物；勇士原地不动，怪物原地消散并飘出金币。伤害 > 0 的永远不打。
  - **留怪等幸运金币**（子开关，默认开）：第二区起、拿到幸运金币（41F 之后）之前不自动清怪，留到金币 ×2 再打；被留下时每层在消息栏提示一次。关闭后第二–四区也会自动清怪。
  - **自动拾取**（子选项「含血瓶」；关闭 = 不含血瓶）：自动收集已打开通路上的道具，道具以「磁吸」动画飞向勇士。不拾取会触发剧情对话的道具（魔杖、备忘录）。序章（3F 伏击前，属性随后会被重置）只自动拾取钥匙。
  - **自动开暗墙**（会剧透）：只打开与勇士当前位置**相邻**的暗墙，相当于「走到墙边时察觉到松动」。
  - 规则：从勇士位置广度优先搜索，只穿过空地以及本批刚清掉的格子；门、墙、楼梯、NPC、未触发的剧情格（3F 伏击点、10F 各剧情格）、带战斗剧情的怪物（2F / 8F 守卫、骷髅队长）都会挡住搜索；**永远不会开门或消耗钥匙**。剧情 / 对话 / 弹窗期间、10F 伏击（击败骷髅队长前）不会触发；某次自动战斗引发剧情时本批立即停止。
  - 每批在消息栏写一行汇总，如「自动拾取：黄钥匙×2、红血瓶×1」「自动清怪：绿色史莱姆×3（金币 +3）」；同批音效每种只播一次。
  - 回退：整批自动动作并入触发它的那一步——按一次「回退」即撤销这一步和它引发的全部自动动作，回退后也不会重新触发。
- **设置**：移动速度 5 档（慢 / 标准 / 快 / 很快 / 瞬移），同时作用于按住方向键连发、点击寻路与勇士移动动画；背景音乐与音效各自的开关和音量；无手册显示伤害的辅助选项；自动清怪 / 自动拾取（含血瓶）/ 自动开暗墙。全部保存在 localStorage。
- **音乐与音效**：全部用 WebAudio 实时合成（无音频文件），芯片音风格。背景音乐两首循环曲：平静的「塔中」主题与 10F 伏击 / 3F 魔王登场时的紧张曲；音效包括脚步、攻击连击、怪物消失、开门、暗墙、钥匙、宝石、血瓶、装备、购买、楼梯、对话打字、错误、回退、存档。首次点击 / 按键时才启动音频（移动端自动播放限制）。
- **暗墙**：比普通墙略暗、带几道细微裂纹（仔细看才能分辨）；点击暗墙会自动走到旁边并撞开（与门的点击方式相同），点击普通墙无反应。
- **对话头像**：勇士、小偷、老人、商人、祝福商人、祭坛、魔王、骷髅队长（第一区 8 个，第二区新增吸血鬼、特殊商人） 64×64 高清像素头像（程序绘制，4 倍放大显示）。
- **第 10 层上楼**：进入第二区 11F。

- **NPC / 商店**：12F 商人 800 金币卖红钥匙、暗墙后的特殊商人 1000 金币一把黄钥匙（可反复买）、12F 祭坛（攻 +4 / 防 +8，与 4F 共用价格）；15F 小偷、15F 商人 200 金币卖蓝钥匙；16F、18F 老人的情报。对话逐字取自原版。

## 道具使用确认 / 道具数值 / 分区音乐

- **使用确认**：镐、圣水等会消耗的道具，在点背包或按快捷键（镐 = 1）时先弹出「是否使用「X」？」。
  - 框里有图标、按当前状态算出的效果和说明，按钮为「使用 / 取消」；Enter / 空格确认，Esc 取消。
  - 确认后的使用可以用 Z 回退。
  - 规则写在背包注册表里：非永久道具默认需要确认，以后的新道具自动生效。
  - 怪物手册、备忘录、魔杖（传送器自带「传送」确认）、十字架是查看类，直接打开。
  - 镐周围没有可破坏的墙时不弹确认框，直接提示原因。

  - 数值 = 原版基础值 × 楼层倍率：第一区 ×1、第二区 ×2、第三区 ×3、第四区 ×4、第五区 ×5，例如 11F 红宝石 +2、红血瓶 +100。
  - 鼠标悬停道具会显示名称与效果；拾取提示用的是同一套数值。
  - 设置里可以关闭，默认开。
- **分区背景音乐**：每区一首合成曲，调式与情绪对应原版 section1–5。

## 与原版的差异（详见 docs/research.md §8）

- 原版没有手册时地图不显示伤害；本作默认相同，另提供可选辅助开关。
- 音乐与音效为原创合成，并非原版曲目。
- 回退、移动速度、存档缩略图是 H5 样板式的便利功能（原 flash 版没有）。
- 10F 骷髅队长可被「复活」的 flash 漏洞未还原。
- 「史来姆」写作「史莱姆」；「游戏手册」统一称「怪物手册」；H5 版专属的作者 NPC 与开局设置未实现。
- 第二区（详见 docs/research.md §12.8）：周围没有可破坏的墙时按 1 不会消耗镐（原版会白白消耗）；20F 包围圈的蝙蝠直接画在地图上（原版为背景层装饰，剧情时才放上）；头目曲为原创合成曲。
- 试玩模式为本作附加功能。

- 第三–五区：领域 / 夹击 / 先攻等特殊能力按 51 号塔实现；分区 BGM 为按原版调性新写的合成曲，非原版采样。
- 用户推荐的「一区 0 祭坛、二区 ≤4、留怪等幸运金币」策略已写入调研笔记与路线工具参数（`SIM_NOALTAR` / `M_MAXALTAR`），但自动搜索尚未找到完整链；现成的 `docs/zone1-route.txt` / `zone2-route.txt` 是策略确认前的可行证明路线。
