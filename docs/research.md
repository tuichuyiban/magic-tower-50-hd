# 第一区（1F–10F）/ 第二区（11F–20F）原版资料调研笔记

> 目标：忠实复刻经典「50 层魔塔」（胡然 / flash 版流传最广的版本）的第一区。
> 本文记录所有来源、交叉核对结果、可信度判断，以及已知的不确定点 / 有意偏差。
> 坐标说明：原始数据是带外圈墙的 13×13，本作使用去掉外圈的 11×11，**本作坐标 = 原坐标 − 1**（x 向右、y 向下，从 0 开始）。

## 2. 核心规则

| 规则 | 原版（A+D） | 本作 |
|------|-------------|------|
| 战斗 | 勇士先攻；每回合伤害 max(0, 攻 − 防)；损失 = (⌈怪物生命 / 勇士伤害⌉ − 1) × 怪物伤害；不能破防不能打 | 相同（沿用已认可的战斗表现） |
| 经验值 | **原版 50 层魔塔没有经验值**（所有怪物 experience = 0，状态栏只有楼层 / 生命 / 攻击 / 防御 / 金币 / 钥匙） | 已移除经验值 |
| 宝物数值 | 按区域倍率 `ratio`（第一区 1，第二区 2…）：红血瓶 50、蓝血瓶 200、红宝石攻击 +1、蓝宝石防御 +1 | 相同 |
| 装备 | 铁剑攻击 +10（5F），铁盾防御 +10（9F） | 相同 |
| 楼梯落点 | 上楼落在目标层 `downFloor`（下楼梯旁），下楼落在目标层 `upFloor`（上楼梯旁） | 相同，见 §4 表 |
| 怪物手册 | 3F 老人赠送；**没有手册时地图上不显示伤害**（D：`control.js` `if (!core.hasItem('book')) return`） | 默认与原版一致；存档菜单中可勾选「未获得手册时也显示伤害」作为辅助 |
| 魔杖（楼层传送） | 51 号塔在开局事件 `startText` 中执行 `setValue item:fly = 1`，即**开局就拥有**魔杖（1F 地上另有一根）；只能飞往到过的楼层，`flyNearStair` = 必须站在楼梯上或楼梯四邻；去更高层落在其 `downFloor`，去更低层落在其 `upFloor`（D：`flyTo`） | 相同（开局即有；1F 的魔杖保留在地图上） |
| 备忘录 | 5F 的「备忘录」（id `wand`），自动记录老人 / 商人的情报对话（A：公共事件「记事本」，按 `flag:对话N` 列出） | 相同（只记录情报对话） |
| 暗墙 | `fakeWall`：外观与墙相同，`trigger: openDoor` 且无需钥匙 —— 撞上去即打开 | 相同（外观完全与墙一致） |
| 机关门 / 铁门 | `specialDoor`（机关门）、`steelDoor`（铁门）：不能用钥匙开，只能由事件打开 | 相同 |
| 空气墙 | 10F 骷髅队长周围一圈不可见、不可通行（A 的还原项） | 相同 |
| 自动寻路 | 终点可为怪物 / 门 / 道具 / NPC，途中不经过不可通行格，途中道具会被拾取 | 沿用上一阶段实现（并加入 NPC、剧情格中断） |

## 6. NPC、商店与剧情（逐条取自 A 的事件数据）

### 序章与 3F 魔王伏击
- 勇士以 **生命 1000 / 攻击 100 / 防御 100**、装备 **神圣剑 / 神圣盾** 从 1F (5,10) 出发（0 把钥匙）。序章里 1–3F 的怪物都是 0 伤害，可以白拿金币 / 钥匙；但宝石、血瓶在伏击后会被属性重置「浪费」。
- 3F 踏上 (4,8)：魔王（redKing）出现在 (4,6)：「欢迎来到魔塔，你是第一百位挑战者。你若能打败我所有的手下，我就与你一对一的决斗。现在你必须接受我的安排。」四名魔法警卫出现在 (4,7)(3,8)(5,8)(4,9)；勇士：「什么？」→ 黑场、受击音效 → **生命 400、攻击 10、防御 10，神圣剑 / 神圣盾被夺走** → 传送到 2F 牢房 (2,7) 面朝下 →「------ 喂！醒醒！」。剧情结束后 (4,6) 变为通路。

### 2F 监狱
- 小偷 (2,6)：「你清醒了吗？你到监狱时还处在昏迷中，魔法警卫把你扔到我这个房间。但你很幸运，我刚完成逃跑的暗道你就醒了，我们一起越狱吧。」→ 打开牢墙 (1,6)，小偷向左 2、向下 2 走到 (0,8)。
- 再与小偷 (0,8) 对话：「我们终于逃出来了。你的剑和盾被警卫拿走了，你必须先找到武器。我知道铁剑在5楼，铁盾在9楼，你最好先取到它们。我现在有事要做没法帮你，再见。」→ 向下走 2 格后消失。
- 铁门后的老人 (10,3)：「谢谢你救了我，为了感谢你的帮助请收下这些礼物.（收到1000金币）」→ 金币 +1000。
- 铁门后的祝福商人 (10,6)：「谢谢你救了我，我能用祝福魔法提升你 3% 的攻击力和防御力。现在就提升吗？」（现在提升 / 等会再说）→ 攻击、防御各 + round(×0.03)。
- 击败 (5,1)、(7,1) 两名中级卫兵后打开 6 扇铁门 (4,4)(4,7)(4,10)(8,4)(8,7)(8,10)。**第一区内打不过中级卫兵**，所以老人与祝福商人要到后期才能救出 —— 已实现，但第一区内不可达（与原版一致）。
- 右下的另一名小偷（35 层剧情）初始隐藏，未实现（属于第四区内容）。

### 3F 老人：怪物手册
- (10,3)：「我可以给你怪物手册. 你可以用快捷键 X 去使用它。它能预测出当前楼层各类怪物对你的伤害。」（谢谢）→ 获得怪物手册，老人消失。本作 X 与 M 都能打开手册。

### 4F 祭坛（商店）
- 祭坛位于 (5,0)，两侧 (4,0)(6,0) 为装饰。循环菜单：「如果供奉${价格}金币, 便可以增加你的力量, 你想要什么呢…」
- **价格 = 20 + 10 × t × (t + 1)**，t 为已供奉次数（全塔祭坛共用计数）：20、40、80、140、220、320…
- 选项：生命 + 100 × (t + 1)、攻击 + 2 × ratio、防御 + 4 × ratio、离开；金币不足：「你的金币不足${价格}枚，无法供奉！」
- 老人 (9,0)：「有些门不能用钥匙打开，只有当你打败它的守卫后才会自动打开。」

### 6F / 7F 商人
- 6F 商人 (7,3)：「我有一把兰钥匙你出50个金币就卖给你。」（我太需要了 / 下次再说）→ 50 金币换 1 把蓝钥匙；买过后再对话：「魔塔一共50层，每10层为一个区域。如果不打败此区域的头目就不能到更高的地方。」随后消失。（「兰」为原文写法，保留）
- 6F 老人 (3,7)：「你购买了礼物后再与商人对话，他会告诉你一些重要的消息。」随后消失。
- 7F 商人 (5,0)：「我有五把黄钥匙你出50个金币就卖给你。」→ 50 金币换 5 把黄钥匙；买过后：「在商店里你最好选择提升防御，只有在攻击力低于敌人的防御力时才提升攻击力」随后消失。
- 金币不足：「你的金币不够50枚，无法交易！」

### 8F 机关门
- 击败 (8,4)、(10,4) 两名初级卫兵后，(9,3) 的机关门打开，里面是红钥匙（第一区唯一一把，用于 10F 红门）。

### 隐藏要素（第一区）
- **5F 暗墙** (8,10)：外观与墙相同，撞开后通往铁剑 (10,10)。
- **9F 暗墙** (9,4)：撞开后通往铁盾 (8,6)。
- 10F 隐藏的上楼梯：击败骷髅队长后才出现。

### 10F 头目战
1. 走过红门 (5,8) 进入骷髅队长前方的小屋，踏上 (5,4) 触发伏击：身后 (5,6) 关闭为机关门；两侧小屋的机关门 (3,3)(7,3) 与牢墙 (4,5)(6,5) 打开；空气墙消失。
2. 骷髅队长：「哈哈哈, 你是如此的幸运能安全到达这里。 但现在好运离你而去了，你中埋伏了，弟兄们给我上。」队长退到 (5,0)，(5,2) 关闭为机关门；6 只骷髅人与 2 只骷髅士兵从两侧小屋走出，围住勇士周围 8 格（左右小屋的门随后关闭）。
3. 8 格全部清空后，(5,2) 的机关门自动打开（A 的 autoEvent）。
4. 踏上 (5,1)：「你怎能杀出重围？我是决不会让你通过的，来吧，我要与你决斗!」
5. 击败骷髅队长：「不,这是不可能的， 你怎会打败我！ 你别太得意，后面还有许多强大的对手和机关存在，你稍有疏忽就必死无疑。」→ 两侧小屋出现奖励：3 红宝石、3 蓝宝石、3 蓝血瓶、3 黄钥匙；机关门打开、红门移除、上楼梯出现。
6. 之后经过 (5,8)：小偷从左下走来：「嘿！我们又见面了！非常感谢你打败了此区域的头目。我正苦恼于如何到更高的楼层，现在我终于可以上去了。 我听说银盾在11楼，银剑在17楼，这消息不知道对你是否有用。」然后走上楼梯离开。
- A 还原的 flash 特性：未触发伏击就走到 (5,0) 也会判定战胜。正常流程不可能发生，本作照搬该判定。

## 8. 不确定点与有意偏差

1. **魔杖、备忘录的名称**：A 中 id 为 `fly` 的道具叫「魔杖」（楼层传送），id 为 `wand` 的叫「备忘录」—— 与部分玩家记忆中的「楼层飞行器」等叫法不同。采用 A 的名称。
2. **初始提示**：A 开局有作者设置（flash 特性开关、疯狂加血、赠送弱化楼传）—— 均为 H5 版专属，不实现；也不赠送弱化楼传（I333）。
3. **地图伤害显示**：原版需要怪物手册；为照顾已经习惯的玩法，存档菜单提供「无手册也显示伤害」开关（默认关闭 = 原版）。
4. **临界数字**：沿用上一阶段的约定（无可提升时不显示 0）。
5. **10F 骷髅队长可被复活的 flash bug**（A 作者注：杀死队长后再次触发机关会复活）：不还原（触发器只执行一次）。
6. **魔王 / 魔法警卫**只在 3F 剧情中出现，不能战斗（与原版一致）。
7. **剧情演出**：原版音效未实现，改为闪白 + 黑场 + 楼层横幅；NPC 行走动画约 200ms/格。
8. **手册名称**：A 的道具名为「游戏手册」，但 3F 老人的台词说「怪物手册」；本作统一称「怪物手册」。
9. **怪物名**：A 写作「史来姆」，本作用通行写法「史莱姆」。

### 12.10 第二区可通关性（`npm run route2`，结果 `docs/zone2-route.txt`）

方法：
1. `scripts/simulate2.ts` 的束搜索（与第一区相同的框架，真实 Game + Director）。共跑 10 组参数：宽度 25–120，「银盾先 / 银剑先」两种里程碑顺序。全部失败，最远 17F（60/74），钥匙或生命耗尽。束搜索保留为实验选项（`SIM_BEAMSEARCH=1`）。

   - 7F / 15F / 12F 商人；
   - 卡住时喝圣水。

## 上古版变体（开局可选：36F 暗道 / 48F 隐藏白衣武士）

用户反馈：「有些版本在 36 层有暗道，并且在 48 层左上角有隐藏的白衣武士」，第二轮又反馈「36 层暗道与大众版不一致」。h5 51 号塔（经典版，本项目的数据基准）里 MT36 / MT48 都没有这两处机关（MT36 `events` 为空、36F 老人说「4种移动宝物」；MT48 机关门 `specialDoor` (8,8) 没有任何开门事件，38F 商人提示「存放圣剑的房间的门坏了，你必须用镐破墙而入」）。

### 第二轮：改用原作数据（不再推断）

**h5 魔塔广场的检查**（按用户建议，2026-10-20）：
- 首页列出的 50 层系复刻只有 `51`（50层魔塔，2026/1/1 全新复刻版）和 `51_xinxin`（50层魔塔新新版），另有 `xinxin`（新新魔塔 v1.1，56 层，另一座塔）。
- 直接取 `https://h5mota.com/games/51/project/floors/MT36.js`、`MT48.js` 与 `https://h5mota.com/games/51_xinxin/project/floors/MT36.js`、`MT48.js`：两座塔的 MT36 地图逐格相同，都没有暗墙，`events` 为空；MT48 同样没有隐藏怪。
- `51/project/data.js` 里没有「上古」难度分支。猜过的 `51_shanggu`、`shanggu`、`51_classic` 等名字都返回 404。
- 结论：**h5 魔塔广场上没有「上古版」的数据**。

**真正的数据源：原作 Tower of the Sorcerer for Windows 1.2 的地图表。**「上古版」就是汉化 Flash 版之前的日 / 英原版：萌娘百科、newton 百科都说「原版 36 楼有 4 个隐藏在墙壁中的密道，汉化者没有发现」，汉化时老人的话也被改成了「4 种移动宝物」。
- 仓库 <https://github.com/fyt000/Tower-of-the-Sorcerer>（TSW 1.2 的 C++ 重写 / Delphi 反编译）里有 `cpp/src/original_constants.hpp`，地图表是从哈希固定的 TSW 1.2 EXE 中提取的，每层 121 格。
- tile 编号：`9 = SecretWall`（暗墙）、`7 = SpecialRoad`（看起来是空地的机关格）、`93 = Sorcerer`（魔导士 = 汉化版「魔法警卫」，即本作的白衣武士 whiteKing）、`4 = SealedGate`（机关门）。

与各攻略的描述逐条吻合：
- 游民星空：「36 层撞暗墙上 37（途中需要两把黄钥匙开门，除中间一个鬼战士以外全部无伤，剑士战士骑士一个都不打）」。对应路线：
  1. 下楼 → 打 (10,2) 幽灵（史莱姆人）。
  2. 走右上暗道到 (7,0)，打 (6,0) 兽人武士。

原版 48F（`// Floor 48`）：
- 左上角 (0,0) 是 `7 SpecialRoad`。`special_road()` 在 48F 调用 `check_floor()`，到达场景（`scenes.cpp` `case 48`）把 (0,0) 设成 `Sorcerer`。也就是说，勇士碰到这格「空地」时，魔法警卫在那里现身。
- 击败后 (0,0) 变成 `6 Road`，`floor_checks.cpp` `case 48` 检查到「(0,0) + (7,7) == 10」（空地 6 + 机关门 4），打开圣剑房间的机关门 (7,7)。
- 本作实现：开启后 48F (0,0) 是隐形空气墙（看起来是空地），撞上时白衣武士现身；击败后打开 (7,7) 的机关门。
- TapTap 攻略说的「最左上角往下的格子」，指的是从 (0,1) 往上撞最左上角的那一格。第一轮实现误放在 (0,1)，已改正。
